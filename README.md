# 🌐 Basic Web-Based Portfolio

A personal portfolio website built with **HTML, CSS, and JavaScript** to showcase my skills, projects, experience, and contact information as a Computer Science student and aspiring Full-Stack Developer.

## ✨ Features

* Responsive design
* About Me section
* Skills & proficiency
* Projects showcase
* Experience section
* Contact section
* Social links
* Scroll animations
* Mobile-friendly layout

## 🛠️ Technologies

* HTML5
* CSS3
* JavaScript
* Git & GitHub
* Vercel

## 🚀 Run Locally

```bash
git clone https://github.com/AbubakerAfzal01/Basic-Webbased-Portfolio.git
cd Basic-Webbased-Portfolio
```

Open `index.html` in your browser or use **Live Server** in VS Code.
